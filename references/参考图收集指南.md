# 参考图收集指南（你从 Pinterest / 小红书 找图给我）

> 目的：把你刷到的"对味"图片变成可执行的视觉锚点，钉死 app 风格。

## 一、怎么给我（任选）
- **方式 A（推荐）**：在 `references/` 里建子文件夹，比如 `references/我的参考/`，把图存进去，然后告诉我文件夹路径，我来读。
- **方式 B**：直接把截图贴在对话里，一张张发也行。

## 二、每张图打一个标签（关键！否则一堆图我分不清借哪点）
存图时顺手命名，或发图时配一句，格式：
`[标签] 图片` —— 标签从下面挑：

| 标签 | 意思（这张图我想借鉴什么） |
|------|--------------------------|
| `配色` | 整体色调 / 某个颜色搭配 |
| `卡片` | 卡片形状、圆角、阴影、留白 |
| `插画` | 食物 / 图标 / 角色画法（圆润？手绘？扁平？） |
| `字体` | 中文字体感、标题处理方式 |
| `动效` | 配送 / 等待 / 彩蛋的动效感觉 |
| `调性` | 整体氛围（治愈？高级？可爱？） |
| `某屏` | 特指某个界面，如 `店铺列表屏` `购物车屏` `结局彩蛋屏` |

例：`[调性] 韩系治愈外卖app.png`、`[卡片] 圆角软卡片参考.jpg`、`[店铺列表屏] 小红书某博主截图.png`

## 三、附一句"风格方向词"
你刷到的图大多有流派，给我一个词我就能翻成设计 token：
- 韩系治愈 / 日系极简 / 奶油风 / 莫兰迪 / 复古手绘 / 萌系圆体 / 性冷淡高级
- 例："我想要偏**韩系治愈 + 一点奶油风**，不要性冷淡"

## 四、数量建议
**10–20 张足够**，别太多。多了反而风格打架。优先收：
1. 2–3 张"整体调性"代表（定方向）
2. 3–5 张具体界面（定布局 / 卡片）
3. 3–5 张插画 / 图标 / 字体（定细节）

## 五、我会怎么用你给的图
1. 提炼成 / 修正 **Figma Variables**（配色、圆角、阴影、字体），和你之前给的 `frontend_design_spec.md` 对齐。
2. 更新 `references/` 里的 moodboard，把你的图和我生成的对齐成一套。
3. 作为 **7 屏设计**的视觉锚点（Figma 里照着搭 / 给 AI 工具当"照这个做"的图）。
4. 若某屏还缺感觉，我用 ImageGen **按你给的方向补生成**针对性参考。

> 一句话：你负责"定味"，我负责"翻译成 Figma token + 落地"。你不用懂设计，只要把对的图带来、告诉我借哪点。

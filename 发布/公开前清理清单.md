## 二、两条路，选一条

### A. 一个仓库，公开版只放该放的（省事）

现在索引已经干净了，直接推就行。缺点：**历史里还留着**（第一次 commit 就带上去了），
`references/` 那 50MB 会一直压在 `.git` 里。想彻底干净只能重建历史（`git checkout --orphan`）。

### B. 两个仓库（最干净，推荐给「想当作品集」的情况）

- **私有仓库**放全部（含归档、笔记，什么都不用改）。
- **公开仓库**只放：`src/` `public/` `index.html` `vite.config.js` `package.json`
  `package-lock.json` `README.md` `tools/`（守卫脚本是这个产品的说明书，值得放）。

```bash
mkdir ../soft-life-public && cd ../soft-life-public
cp -R ../虚拟外卖模拟器/{src,public,tools} .
cp ../虚拟外卖模拟器/{index.html,vite.config.js,package.json,package-lock.json,README.md} .
git init && git add . && git commit -m "init: 慢活小铺"
```

⚠️ 拷完在**新目录**里跑一次 `npm install && npm run build`，确认脱离原目录也能跑起来。

## 四、GitHub Pages 怎么出 `dist/`

`dist/` 在 `.gitignore` 里（这是对的），所以 Pages **不能直接读它**。两条路：

- **用 GitHub Actions**：CI 里 `npm ci && npm run build`，再把 `dist/` 发到 Pages。（推荐）
- 或者本地 `npm run build` 后，把 `published-site/` 推到 `gh-pages` 分支。

⚠️ `vite.config.js` 里的 `base: './'` **不要动** —— 正因为是相对路径，放在
`https://<你>.github.io/<repo>/` 这种子路径下资源才不会有 404。

## 五、还要决定一件事：许可

现在没有 `LICENSE` 文件，法律上等于**保留所有权利** —— 别人不能合法复用。

- **MIT**：随便用、随便改，署个名就行。
- **CC BY-NC 4.0**：可以改，但不许商用。**对这个题材可能更贴** —— 免得有人拿去做成收费的「疗愈 App」。

选定后，把 `README.md` 末尾「尚未选定开源许可证」那段同步改掉。

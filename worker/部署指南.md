# 统计 Worker 部署指南（soft-life-stats）

> 前端代码（`src/stats.js` + `AdminScreen`）已经就绪，只差把 Worker 部署到 Cloudflare 这一步。
> 部署前，`src/stats.js` 里是占位符，前端会**静默不统计**（本地开发零打扰）。

## 一、你要准备什么

- 一个 Cloudflare 账号（免费版即可，Workers 免费额度每天 10 万次请求，这个小铺够用）
- 本地装好 `wrangler`（`npm i -g wrangler`，或 `npx wrangler`）

## 二、部署步骤

```bash
cd worker

# 1. 建 KV namespace（只建一次，会返回一个 id）
npx wrangler kv namespace create STATS

# 2. 把返回的 id 填进 wrangler.toml 的 [[kv_namespaces]] id = "..."
# 3. 设管理密钥（你自拟一串，跟 src/stats.js 里的 STATS_ADMIN_KEY 保持一致）
npx wrangler secret put ADMIN_KEY

# 4. 发布
npx wrangler deploy
```

发布成功后会得到一个地址，形如 `https://soft-life-stats.<你的子域>.workers.dev`。

## 三、回填前端

打开 `src/stats.js`，改两个常量：

```js
export const STATS_ENDPOINT = 'https://soft-life-stats.<你的子域>.workers.dev'  // 去掉「你的名字」
export const STATS_ADMIN_KEY = '<你上面 secret put 时填的那串>'
```

改完 `npm run build` 重新发布前端即可。

## 四、验证

- 前台：随便点几下（下单、捐猫粮、贴手账），控制台无报错即可。
- 后台：线上地址加 `?admin=1`，应能看到四类数字（打开/订单/猫粮克数/照片）+ 每日序列 + DAU。

## ⚠️ 安全注意

- `STATS_ADMIN_KEY` 会被打进前端 bundle（`?admin=1` 是公开入口）。**这是本项目的已知取舍**：后台只展示匿名聚合数字、不含任何个人信息，泄露密钥最多被人看到统计大盘。若以后要接真敏感数据，需把鉴权挪到服务端、前端只做登录态。
- Worker 只记四类匿名数字（visit / order / grams / photo），`随机访客 id` 仅用于「同一天去重」，连不上账号或设备。

## 预览稳定性（白屏根因已找到并修复）
- **白屏根因**：项目缺 `vite.config.js`，Vite 默认 `base:'/'`，导致 `dist/index.html` 里资源引用是绝对路径 `/assets/xxx.js`。这样 file:// 双击、workbuddy 内置静态预览都加载不到 JS/CSS → 白屏。
- **修复**：新建 `vite.config.js`，设 `base:'./'`（+ react plugin），重新 build 后资源引用变为相对路径 `./assets/xxx.js`。从此 file:// 双击、任何静态服务器、workbuddy 内置预览都能正常加载。
- sandbox 里 vite preview / python http.server nohup 进程在 agent turn 结束即被杀，localhost 不稳定。
- 教训：Vite 静态站点要能双击打开，必须 `base:'./'`。

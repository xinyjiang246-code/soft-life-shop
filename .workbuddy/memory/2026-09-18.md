## 字阶层 · 三声部（提交 `6b32f98`）

**用户原话**：给了一张参考图（斜体黑衬线写 `pick it, wait for it, keep the joy.`）+
「这个英文字体比较好看 就是字体不能所有的都一样，需要有些突出之类的」。

**判断**：不是字体的问题，是**声部**的问题。09-17 那版把全站收敛进五支角色字体做对了，
但顺手把层级也压平了 —— 51 处 `var(--f-serif)` 里 45 处都是 `w500`，中文大标题也全是 500，
「大标题」和「小标签」只差字号。实测印证：首页 115 个可见文字块里 Fraunces 只占 5 个，
PingFang 400/500 占 72 个，整页一条直线。

**做法**：不引新字体，只在同一支 Fraunces 之内开三档。
- ① 重音 display：斜体 **800** + `font-variation-settings:"SOFT" 0,"WONK" 1`
  → 只有 4 处落点：`.brand`（Soft Life 店招）· `.section-title` · `.product-section h1` · `.ending-aside`
- ② 标题 headline：正体 500 → 600（价格与大数字：bottom-price / cart-price / archive-bar span /
  pet-stat-num / ledger-stat b / rescue-tally b / charity-hero-num）
- ③ 中文大标题：500 → 600（中文落宋体 → Songti Bold；hero / store-head / ending-title / world-hero …）
- `.section-title em`（计数字）显式退回 upright 500 —— 一行之内造落差，否则 em 继承 800 等于白加。
- `@import` 改成变量区间 `ital,opsz,wght@0,9..144,400..900;1,9..144,400..900`
  （原来 `1,9..144,500` 只给斜体 500 → 800 会是伪斜体）。
- `opsz` 不写死，交给 font-optical-sizing 跟字号走。

**顺带两件**：
- 结局页 `that's the soft life` 从 `ending.body` 里拆出来独立成行（新 `.ending-aside`，19px），
  它是小铺的「声音」，之前混在 13.5px 正文里 —— 最该响的一句反而最轻。
- `text-wrap: balance` 治孤字行：结局标题「今天你把自己照顾得很好」11 字 ×28px = 308px，
  卡片内宽 292px → 原本断成 10+1，最后那个「好」孤零零占一行；均衡断行切成 6+5。

**清掉 25 处跑掉的旧字体**（`tools/migrate-stray-fonts.py`，按选择器逐个路由，不 replace-all）：
Quicksand / Nunito / Cormorant Garamond 还在文件里，**其中 8 处是带反斜杠的**
（`\"Quicksand\"`）—— CSS 里那是「标识符里的引号字符」，跟字体名不等价 → 整条 font 声明
静默回退到 system-ui / 通用 serif。DishArt 的 SVG 里 3 处 Nunito 也换成 Space Mono。

### ① 首屏没说清这是什么（最要紧）

- 首页唯一一句解释产品的话是 `.hint-bubble`，而 `getTodayHint()` 七条里**五条是标准外卖促单话术**
  （「到饭点了，要不要点份便当照顾一下自己？」「购物篮里还有 N 样东西，要现在下单吗？」）。
- **与核心概念直接矛盾**：小铺讲「不饿也可以点」，hint 讲「到饭点了」。
  购物车那条尤其伤 —— 与「心愿单文案不许催单」是同一条红线，只是没人管到 hint。
- 只有 `pet`（「你已经少点了 N 次外卖」）和 `night`（「先给自己倒杯水」）两条真有小铺性格。
- **「这是虚拟的」第一次出现是在结算页**（CheckoutScreen：「不会真的扣款，也不会真的送来任何东西」）。
  陌生用户要走完 挑选→加购→结算 才知道。首页下半有 `.shop-list-sub`「全部虚拟」，
  但首屏看不到 —— 定位既然是「面向陌生人的开放产品」，第一眼就必须交代。

### ② 数据与传播都没有出口

- 手账里是**用户真拍的照片**（IndexedDB），公益账本是 localStorage；公益页自己写明
  「所有数字都记在你自己的浏览器里」。但**全站没有任何导出/备份入口** —— 清缓存/换设备即全失。
- **从未上线**：无 `netlify.toml`/`vercel.json`/CI，package.json 只有 dev/build/preview。
  `base:'./'` 说明当初就是为任意路径静态托管准备的，dist 是纯静态 —— 随时可发。
- **零分享能力**：无 `og:image`/`description`/manifest/icons（index.html 只有 charset/viewport/
  theme-color/title）。结局页与手账页做得很讲究，链接发出去却是个白卡片，也加不了主屏幕。

### ③ 视觉可改（用户最在意的一类）

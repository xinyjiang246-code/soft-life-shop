## 第四轮：打磨（用户要求「先打磨好，不要弄多」）
发现并修了 3 处问题：
1. **软软「换一句」按钮完全失效（真 bug）**：`refreshLine` 只 return 新值，没有写入 state。改为 `useState` + `lineIdx`，并加 `swapping` 状态做淡出淡入动画；宠物升级后话池变化用取模兜底。
2. **主色提取会被白盘/浅色桌面污染**：原算法统计全图像素，主色常变成米白。新算法双桶——优先统计「饱和度 > 0.15 且亮度 35~232」的彩色像素，只对彩色像素聚类；彩色占比 < 6% 时回退全图。同时去重相邻色桶、扩展色彩命名（干净米白/森林绿意/雾蓝午后/暖橘焦糖等）。
3. **上传后 AI 内容瞬间弹出，没有「在思考」的感觉**：新增 `AnalyzingState` 组件——四步文案轮播（读取像素→识别色调→匹配语料→生成小记）+ shimmer 骨架屏，分析完再逐条揭晓 4 个模块（280ms 间隔）。
- 另修：`input.value = ''` 允许重复选同一张图；同色系推荐改为按主色 hash 固定，不再每次刷新都跳。
- Build 通过（`index-DuxO1ipK.js`），8080 稳定。

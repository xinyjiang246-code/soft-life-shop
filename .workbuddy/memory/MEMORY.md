# 慢活小铺 · 项目长期约定

> 只留「下一个人接着做必须知道」的决策与红线。**操作细节与 95 条坑点一律见 skill `soft-life-web-dev`**，用户原话见各日 `YYYY-MM-DD.md`。

## 一、是什么 / 为什么

- **初衷**：不饿/吃撑时仍想点一次外卖 —— 要的是下单仪式；食物不被真消耗，钱流向公益（捐猫粮按克计）。
- **结构** = 真外卖 App：`home → counter → cart → checkout → delivery → ending →（捐猫粮）→ charity`；`world`（世界菜单）· `rescue`（惜食柜）两条独立入口走同流程，返回用 `from` 参数。
- **6 家店**：tea / bento / dessert / life / noodle / dimsum。**不再开新店新品类**。
- **定位（2026-09-16 定档）**：面向陌生人的开放产品，走「一个人的仪式」，**不用后端**——钱是真的、转账用户自己走，App 只做换算克数 + 记账。红线：**绝不暗示"我们替你捐了"**；需「我真去捐了」闭环出口。给 AI 起私名提案已撤回（"我" = 小铺统一声音）。
- 规模红线（用户原话「我们现在比较小」）：欠 4 样食物（自创咖啡+2 面包，韩料不重做）；**别再自己加东西**。

## 二、商品图

- 一律 `ItemArt.jsx`（real=店铺/购物袋，draw=小店/手账）；无图用 `DishArt` 蜡笔 SVG，**禁 emoji**；每款两张独立图（禁上下拼接），翻面 `FlipImage`；WebP，**禁 1MB PNG 进 dist**。
- 生成确定性：种子只来自 `(城市,批次,日期)`，**绝不用 `Date.now()`**。
- 世界/惜食商品不进 `getAllItems()`，只挂 `getItem()`。

## 三、公益

`CHARITY`：10g/元、60g/猫日、**默认 30%（不鼓励全捐）**、presets [10,30,50,100]；key `soft-life-charity-v1`。档案页必须诚实「这是一本账，不是一次转账」。

## 四、配送等待 · 慢活额度（核心机制）

时间是唯一真实资源 → 给时间定价，**不加小活动**。额度 `soft-life-patience-v1`：每天 10 分钟，快进按 `ceil(剩余秒/60)` 扣；不够则禁用；**等满不扣还多掉贴纸**。加速 = **催单仪式**（三选一问候→骑手回话→结局），**永不退回一键跳过**。等待页四件套：骑手来信 / 软软陪等 / 现实小事 / 额度面板。
- **陪等方式三选一（2026-09-17 用户拍板「三种都想要，要能切换」）**：walk 陪他走 / road 帮他看路 / offline 先下线；`soft-life-wait-mode-v1` 记住上次。**小游戏口径已改写**：可以做，但不计分、不会输、**不点也完全没事**（三条写死在 `RIDER_MOMENTS` 注释里）。walk 的选择进结局页「路上的纪念」——只记事，**不给奖励**。
  🔴 **2026-09-18 结构定死：三种方式必须「互斥切换」，不是「常驻进度窗 + 追加模块」**。第一版把玩法追加在「骑手骑到哪了」下面，选完要往下滑才看得见 → 用户直接说「选了没变化」。现在统一挂在一张 `.wait-deck` 外壳下：抬头行（图标 + 方式名 + 还有多久）**随模式一起换**，主体三选一。三个子组件（RiderWindow/RiderHop/FoldRitual）**只出主体，不许再自带抬头**。守卫 `verify-wait-modes.mjs` 盯死这条（切过去后另两个主块不许在 DOM 里）。

## 五、首页

- hero = 杂志内页（THE SOFT HOUR）；改高度同步 `.hero-cap`。
- 四件套：氛围条 · 每日心情（`soft-life-mood-v1`）· 软软串门 · 2×2 磁贴（统一水彩图；**别再塞新入口**；猫视角 = 正面平视左右对称，不妥协）。
- 顶栏搜索/心愿单是真入口；新增商品能力**同步进搜索索引**。心愿单语义 =「先记着不急着点」，文案不许催单。
- 🔴 **UI 视觉改造（2026-09-16 暂停 → 2026-09-17 重启）**：暂停期用户原话「完全没有变 chic 你就先别变了」「你做的太丑了」，规矩是**用户不给方向就不动任何页面视觉、不许自己归纳方向**。
  9-17 用户给了方向（另一 agent 做的「Paper Press 纸感 demo」：认可它的**字体与整页统一**，保留我们的图）→ 据此分两刀落地：
  **① 字型层**：全站字体改从 `:root` 五个角色变量取（Fraunces / Space Mono / 苹方 / 宋体 / 楷体），微标签统一 Space Mono，两支 scope mono 合并指向同一支 mono。
  **② 印刷层**：只取四样 —— 颗粒纸面 · 硬阴影（偏移实色，只给能按下去的东西）· 1px 实线 · 印章（结局页角章「已送达」）；**不吃**大圆角+柔和阴影那一路。
  9-18 用户给了新方向（一张**斜体黑衬线**参考图 +「字体不能所有的都一样，需要有些突出」）→ **③ 字阶层**：
  统一 ≠ 全都一样。只在同一支 Fraunces 之内开三档（不引新字体）：
  **重音**（斜体 800 + WONK 轴）：`.brand` 店招 · `.section-title` 栏目名 · `.ending-aside`（结局那句英文，从正文里拆出来独立成行）；
  **标题**（正体 500→600）：价格与大数字；**中文大标题**（500→600，落宋体 Bold）。
  🔴 **重音层靠「少」成立** —— `verify-typekit.mjs` [4] 写死上限 5，加重音落点必须同一次把上限一起调。
  结局标题用 `text-wrap: balance`（否则「今天你把自己照顾得很好」会留一个孤字「好」在第二行）。
  三刀都**没动布局、配色、图片**。守卫 `verify-typekit.mjs` + `verify-print.mjs`。下一页（demo 的页码/装订线等）等用户点头再做。

## 六、软软（猫）与表情

- 形象 = 猫（别退回兔熊 SVG）；氛围词用「小饼干」不写「猫粮」。素材 `assets/pets/`；两条取图出口 `.pet-photo` / `.neighbor-cat`，**用 glob 的 key 取 value**，改一条验收另一条。出图链 petForge → **必须顺手 petKnockout**。
- 点它要有形变反应（`petTouch.js` + `PetPops.jsx`）；三层动画分开挂（同元素两个 transform 会互相覆盖）。
- 表情（2026-09-17）：`petFace.py` 量锚点 → noeye 图（**MaxFilter 膨胀，禁扩散填充/腐蚀**）→ `PetFace.jsx` 重画五官；锚点文件 `src/petFace.js` 别手改。七表情（squint/bliss/smile/purr/startle/heart/star）。**只有宠物页传 `faces={true}`**（首页开了会吃掉摸猫点击）。量到的点是 **nose 不是 mouth**；嘴尺寸跟眼睛 ry 挂钩；嘴层包两层 `<g>`（CSS transform 盖 SVG transform）。细节见 skill 坑点 53-58。

## 七、惜食柜

定位 =「关门前剩下的几份」，**不是促销**。红线：**不要红色/倒计时/仅剩 N 件/秒杀**。账本主角是份数（份被留下 > 单带走 > 少花 ¥）。规则：每天 3 件、折率 30/40/50%（**互不相同**）、每件 2 份（`addToCart` 层拦截）、独立 `rescue-` id（原价绝不改写）、只挑食物类、种子只来自 `dateSeed()`、记账在结局页。验证：合计走折后价（¥53 非 ¥90）。

## 八、食物手账 · 照片墙（2026-09-17 定稿）

- **图必须是用户自己拍的照片**（入口=相机/相册），不是后端商品图。
- 存储分工（`photoStore.js`）：原图压 1600 WebP 进 **IndexedDB**，localStorage 只留 180px thumb；**删条目必须同时删照片**。
- **一套照片，两个看法**（用户裁决）：手账是唯一存储；「存下这一餐」页 = 上传 + AI 小记 + 照片墙。共用：备注卡 `EntryDetail.jsx`、常量 `journalMeta.js`、字段白名单 `JOURNAL_FIELDS`（新增字段只改这里）。两步点开：`.jh-peek`（**必须不透明**）→ `.jh-detail-panel`。
- 备注卡字段：日期/名字/店名/这张的心情/那天的心情/为什么想吃/和谁在哪/热量（想记就记）/AI 小记。**热量规则收窄**：可自记，但**不求和、不设目标、不做趋势图**，绝不参与统计。
- 红线：不记卡路里统计、不算账、不做连续打卡（自查脚本要识别否定句）。记账时机 = 结局页（与宠物成长/公益/惜食同一节拍：**送达才算数**）。列表行上不放删除（详情页二次确认）。
- `.archive-card.has-ai` 让卡片随内容长（修过 AI 面板被裁 394px）；A/B 只需切这个类名。
- 验收集成素材：`tools/seedPhoto.mjs` 用项目真照片（matcha 拿铁）——**交付图里的测试素材必须一眼认得出是食物**；断言阈值从素材推导（别写死 2000 字符/1200px，换素材会假红）。

## 九、技术 / 验证（只留最贵，细节见 skill 95 条坑点）

- 预览：`python3 -m http.server 8080 --bind 127.0.0.1`（cwd=dist/）；别让用户开 `file://`（白屏）；`base:'./'` 不能动。
- **购物袋金额只有一处实现**：`cartBreakdown(cart)`；对账 effect（角标与真实内容一致），新增每日商品来源要挂上。
- ⚠️ **build 绿 ≠ 接线对**（esbuild 不查作用域）：改回调 prop 后 grep 定义 + 真机走到那页。
- ⚠️ **假警报比漏报更贵**：断言失败先怀疑探针，用第二种手段复核，最后才改产品。`waitFor` 条件选「只有成功才出现」的；探针用明确类名；截图前等动画播完（别用 `getAnimations().finished`）；`captureScreenshot` clip 是页面坐标；注入字符串里的正则转义会被 Node 先吃一遍。
- ⚠️ **CDP 截图抓不到动画中间帧**（会等合成器稳定）→ `pause()` + 设 `currentTime` 冻住再截；**记录坐标与截图生效差 ~300ms**，交付图上的指示圈会漂。
- ⚠️ 超几十 KB 不进 localStorage（`storage.js` 写满**静默失败**）；盖层必须不透明（量 alpha）；「状态写了没人渲染」按数据问题查（它从哪进来？在哪被读出去？）。
- 搜中文用 `Grep` 工具（BSD grep 静默失配，`\|` 交替也一样静默失配）；改完 `.mjs` 先 `node --check`。
- **同一文件不要在一次消息里发两个 Edit** —— 会互相覆盖，两边都报成功但只有一处落盘。

## 十一、交互层（2026-09-18，用户「然后我需要一些交互」）

三件事，**都没动玩法 / 布局 / 配色**，全是"摸起来"的差别。

- **① 切页进场**：屏幕根节点的**子元素**做 `opacity` + `translate` 进场（前进从右 10px、返回从左，方向在 `<html data-nav>`），`.bottom-bar` 排除在外。动画 260ms。
  - **两条被实测否掉的路，别走回去**：① 给页面套 transform → `.bottom-bar` 是 fixed，祖先带 transform 会换掉它的包含块，动画期间底栏掉到内容底部；② **View Transitions**（视觉完美、fixed 也安全）但 Chrome 在转场中不让实时内容参与命中测试 → 每次切页 ~260ms **全页点不动**（`pointer-events:none` 也拦不住）。就是它把 `verify-pet-pat` 打红的。
  - 填充必须 `backwards`：`to` 里不写 translate 时 Chrome 解成 `translate: 0px`，而 **`0px` ≠ `none`**，`both` 会永久挂包含块 → 弄坏 `.jh-detail` / `.modal-backdrop` / `.exchange-backdrop`。
  - `html { scroll-behavior: smooth }` 会让 `scrollTo(0,0)` 也变平滑 → 切页要写 `behavior:'instant'`。
- **② 全局点击手感**：`button:not(:disabled)` 统一 transition（权重 (0,1,1) 压得住各页类规则）+ `:active` 时长压到 .07s 回弹曲线；幅度分组：小图标 .86 / chip .93 / 大块面 .994 / 兜底 .97；`.add-button` 仍是印刷层的「硬阴影陷进去」。**用独立 `scale`/`translate` 属性，不用 transform**（和既有 transform 相乘不覆盖）。`.flip-toggle` 例外（会和 3D 翻面打架）。另加统一 `:focus-visible` 环 + `touch-action: manipulation`。
- **③ 加购动线**：`src/flyToBag.js` —— 记住最后一次按下点（真机取指针坐标，脚本点击退化成被点元素中心）→ 一个小圆点走上抛弧飞进顶栏袋子 → 到位后袋子晃一下 + 角标弹一下。**纯视觉，不参与业务**；开了减弱动态效果就只做袋子/角标反馈。
  - 顺手修旧债：购物袋按钮补唯一类名 `.bag-button`（原来和心愿单共用 `.cart-button`，飞点认不出袋子）；`.cart-button` 保留，旧脚本照旧。
  - 购物袋里加减数量 / 合计金额变化都要看得见：`key={qty}` / `key={total}` 重挂元素来重播 `numPop`（React 只改文本不重播 CSS 动画）。
- **守卫 `tools/verify-interactions.mjs`**（7 段）：进场中途 opacity 必须真的在涨（只看 animationName 不算数）/ 结束态 `translate` 必须是 `none` / **进场动画还在跑时真实鼠标点击必须有效**（最贵的一条）/ 转场全程 `.bottom-bar` 的 `rect.bottom` 恒等于视口高 / `CSS.forcePseudoState` 量按下幅度 / 飞点真位移 + 袋子晃 + 角标弹 / prefers-reduced-motion 下全不发生但功能照常。

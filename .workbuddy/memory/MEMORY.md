# 慢活小铺 · 红线清单

> 不是手册。**做法、104 条坑点、脚本用法见 skill `soft-life-web-dev`**；用户原话见各日 `YYYY-MM-DD.md`。
> 太长会在注入时被截断（**尾部先丢**），所以最贵的放最前。

## 一、是什么

- 初衷：不饿 / 吃撑时仍想点一次外卖 —— 要的是下单仪式；食物不被真消耗，钱流向公益（猫粮按克计）。
- 流：`home → counter → cart → checkout → delivery → ending →（捐猫粮）→ charity`。`world`（世界菜单）/ `rescue`（惜食柜）是独立入口，走同一流程，返回用 `from`。
- 6 家店 tea / bento / dessert / life / noodle / dimsum，**不再开新店新品类**（「我们现在比较小」）；欠 4 样食物，**别再自己加东西**。
- 面向陌生人的开放产品，「一个人的仪式」，**不用后端** —— 钱是真的、转账用户自己走，App 只换算克数 + 记账。不给 AI 起私名（「我」= 小铺统一声音）。

## 二、红线（其余章节只讲怎么做）

1. 🔴 **结算页那句是全产品唯一一次揭晓真相**，不许退回旧版「你只是完整地经历了『挑选的快乐』」—— 那是别人也有、最没壁垒的部分。
2. 🔴 **绝不暗示「我们替你捐了」**；猫粮克数**必须等用户真的按下捐赠才出现**（凭证上捐赠前是「—」）。
3. 🔴 **等待凭证只开给等满的那一份，快进买不到** —— 这条规矩本身就是护城河，不是奖励。
4. 🔴 **打卡 / 目标 / 奖励一律不许**：不做连续打卡、不设目标、不做趋势图、不催单；惜食柜不要红色 / 倒计时 /「仅剩 N 件」；手账热量**不求和**。
5. 🔴 **小游戏可以做，但不计分、不会输、不点也完全没事**；walk 的选择只记事，**不给奖励**。
6. 🔴 **三种陪等方式必须「互斥切换」**，不是「常驻进度窗 + 追加模块」（用户原话「选了没变化」）。
7. 🔴 `verify-typekit.mjs` 写死**重音同一页上限 5**，**加了新落点不许顺手把上限抬上去**（重音靠「少」成立）。
8. 🔴 **用户不给方向就不动任何页面视觉、不许自己归纳方向**（暂停期定的，仍有效）。
9. 🔴 **切页进场不许走回两条被否掉的路**：给页面套 transform（换掉 `.bottom-bar` 的固定包含块）/ View Transitions（转场 ~260ms 全页点不动）。
10. 🔴 **公开到 GitHub 前必须清个人 / 他人素材**（第十节）。

## 三、页面 · 视觉

- 首页 hero = 杂志内页（THE SOFT HOUR，改高度同步 `.hero-cap`）+ 氛围条（**内含「今天」**）· 每日心情（`soft-life-mood-v1`）· 软软串门 · 2×2 磁贴（统一水彩图；**别再塞新入口**；猫视角 = 正面平视左右对称）。顶栏搜索 / 心愿单是真入口；新增商品能力**同步进搜索索引**。底部 `.about-shop` 是**全站唯一一处说「我」是谁**。
- 商品图一律 `ItemArt.jsx`（real=店铺 / 购物袋，draw=小店 / 手账），无图用 `DishArt` 蜡笔 SVG，**禁 emoji**；每款两张独立图（禁上下拼接）；WebP，**禁 1MB PNG 进 dist**。种子只来自 `(城市,批次,日期)`，**绝不用 `Date.now()`**（凭证编号同理）。世界 / 惜食商品不进 `getAllItems()`，只挂 `getItem()`。
- 视觉三刀**只动字体与印刷，没动布局 / 配色 / 图片**：① 字型层（全站字体只从 `:root` 五个角色变量取，微标签统一 mono）② 印刷层（只取颗粒纸面 · 硬阴影 · 1px 实线 · 印章；**不吃**大圆角 + 柔和阴影）③ 字阶层（同一支 Fraunces 开三档：**重音**斜体 800+WONK / **标题**正体 500→600 / **中文大标题**宋体 Bold）。下一页（demo 页码 / 装订线）等用户点头。

## 四、软软（猫）

- 形象 = 猫（别退回兔熊 SVG）；氛围词说「小饼干」不说「猫粮」。取图出口 `.pet-photo` / `.neighbor-cat`，**用 glob 的 key 取 value**。出图链 petForge → **必须顺手 petKnockout**。三层动画分开挂（同元素两个 transform 会互相覆盖）。
- **三只猫摸法已统一**：`PetScreen`（150px，传 `faces`，6 部位 + 7 表情）· `HomeCat`（58px）· `.wait-pet`（64px）；后两只也做六部位形变 / 按部位台词 / 心情角标，共用 `petTouch.js`（`zoneFromPoint` / `playPatReaction` / `patLine` / `MOOD_BY_ZONE`）。**接第四只照同一套接，别各写一份**。
- 后两只**不画脸**是因为尺寸（150px 时眼睛约 7×9px，58 / 64px 只有 ~3px），改用**角标**；**想加脸的前提是先放大，那是动布局，得用户点头**。等待页**不加气泡**（会盖住上一张卡），复用卡片原有那行文字当台词出口。
- 别改回去：① 里程碑原按「会话累计点击数」→ 摸到第 3 下不管摸哪儿都说同一句，**把「分部位」整个吃掉**；现按「**同一部位连续摸**」计数。② 摸爪子原配 `startle`（受惊）却配「尾巴慢慢竖起来」（猫语是开心），**表情和话正好相反**。
- 表情：`petFace.py` 量锚点 → noeye 图（**MaxFilter 膨胀，禁扩散填充 / 腐蚀**）→ `PetFace.jsx` 重画；锚点 `src/petFace.js` 别手改。**只有宠物页传 `faces={true}`**（首页开了会吃掉摸猫点击）。量到的是 **nose 不是 mouth**。

## 五、惜食柜 · 手账

- 惜食柜 =「关门前剩下的几份」，**不是促销**；账本主角是份数。每天 3 件、折率 30/40/50%（**互不相同**）、每件 2 份、独立 `rescue-` id（原价绝不改写）、种子只来自 `dateSeed()`、记账在结局页。
- 手账图必须是用户自己拍的照片。原图压 1600 WebP 进 **IndexedDB**，localStorage 只留 180px thumb；**删条目必须同时删照片**。手账是唯一存储；共用 `EntryDetail.jsx` / `journalMeta.js` / 白名单 `JOURNAL_FIELDS`（新增字段只改这里）。两步点开 `.jh-peek`（**必须不透明**）→ `.jh-detail-panel`。记账时机 = 结局页（**送达才算数**），列表行上不放删除。
- 验收素材 `tools/seedPhoto.mjs` 用项目真照片 —— **交付图里的测试素材必须一眼认得出是食物**；断言阈值从素材推导，别写死。

## 六、等待 · 额度 · 凭证

时间是唯一真实资源 → 给时间定价，**不加小活动**。额度 `soft-life-patience-v1`：每天 10 分钟，快进按 `ceil(剩余秒/60)` 扣，不够则禁用，**等满不扣还多掉贴纸**（`waited` 记次数）。加速 = **催单仪式**，**永不退回一键跳过**。陪等 walk / road / offline 三选一，`soft-life-wait-mode-v1` 记住上次；统一挂在一张 `.wait-deck` 外壳下，**三个子组件只出主体，不许再自带抬头**。

- 凭证：`params.wait.waited` 为真才渲染，未等满只给一句诚实说明。三文件别拆散 —— `src/receiptImage.js`（Canvas PNG，字体从 `:root` 取 + 导出前 `await document.fonts.ready`）· `WaitReceipt.jsx` · `EndingScreen.jsx`。纸上五行：收件 / 这一单 / 没变成 / 记下的猫粮 / 今天等满；小字固定「钱还在你手上 —— 记多少，你自己定。」
- ⚠️ 重音规则**只能写字号 / 颜色，禁用 `font` 简写**（会重置斜体 / 800 / WONK）；⚠️ 印章**必须给纸留底边**。
- 背景：同类已成整个品类（韩国 `FoodNeverComes` 131 万次 / 假打针），**机制层面不新**，但那条线**全是假装**（省下的钱只是屏幕上的数字，代价为零）。这里多两样他们没有的：**时间要付代价** + **钱是真的出去**。所以这一步**不加玩法**，只是把已经发生的事做成一张能拿给人看的纸。

## 七、怎么介绍自己（分两半）

做法：**清空 localStorage，当自己是从没听过的人走完整条线**。缺口几乎全在「产品怎么向人介绍自己」，不在功能里。

- **第一次看懂**：`hasVisited()` / `markVisited()`（`soft-life-visited-v1`；判据是「这台设备来过没有」而不是「下过单没有」，读失败**当来过**）；首页底部 `.about-shop`；账本补「可以捐给谁」（投喂点 / 大学猫协 / 救助小店），仍守红线且不催。
- **第二天还来**：每日心情 / 今日特调 / 惜食柜 / 慢活额度 / 手账 / 世界菜单**全是「每日」的，却没有一处把它们串成「今天」** → 氛围条**那张卡里**加一条（`src/today.js` 聚合，不另起卡片）。两态互斥：**A**（今天做过事）`今天等满 N 单` / `存下 N 餐 · 记下 N 克猫粮`；**B**（还没发生什么）`今天的特调是「X」` / `惜食柜 N 份 · 今日空运 <城市>`。
  - **不新增任何存储**（全是已经在记的，只是以前没人读出来，最典型是 `patience.waited`）。日期口径**不同别搞混**：`patience` 与手账用 `YYYY-MM-DD`，`charity` / `rescue` 的 `records[].at` 是 **ISO 时间戳**。
  - 措辞全陈述句，不许「还没 / 快去 / 今日目标」；B 说的是**今天有什么**，不是**你还缺什么**；**心情不算「今天发生过事」**（`MoodRitual` 就在下面，会重复）。**不可点、没有箭头**；分隔线别用 `--divider`（叠在浅色渐变上看不见）。
  - 守卫 `verify-first-visit.mjs`（末段**扫构建产物**查全站红线）· `verify-today.mjs`（**最贵是「跨天」**：注入**昨天**的账必须回到态 B）。

## 八、交互层（都没动玩法 / 布局 / 配色）

- 切页进场：屏幕根节点的**子元素**做 `opacity` + `translate`，方向在 `<html data-nav>`，`.bottom-bar` 排除；260ms，填充必须 `backwards`。
- 点击手感：`:active` 压 .07s + 按尺寸分组 scale（图标 .86 / chip .93 / 大块面 .994），**用独立 `scale` 属性不用 transform**；`.flip-toggle` 例外。
- 加购动线：`src/flyToBag.js` 飞点上抛弧进袋子 → 袋子晃 + 角标弹，**纯视觉不参与业务**；购物袋按钮独立成 `.bag-button`；数量 / 合计用 `key={qty}` 重挂重播 `numPop`。守卫 `verify-interactions.mjs`（最贵一条：**进场动画还在跑时真实鼠标点击必须有效**）。

## 九、技术（细节全在 skill）

- 预览 `python3 -m http.server 8080 --bind 127.0.0.1`（cwd=`dist/`）；**别让用户开 `file://`**（白屏）；`base:'./'` 不能动。判断「服务在不在」用 `curl --noproxy '*'`（本机 curl 走沙箱代理返 502；`lsof -ti:8080` 会匹配到远程连接而误判）。
- **购物袋金额只有一处实现** `cartBreakdown(cart)`；对账 effect 要覆盖新增的每日商品来源。
- ⚠️ **build 绿 ≠ 接线对**（改回调 prop / `useMemo` 依赖数组后必须真机走到那页）。⚠️ **假警报比漏报更贵**：断言失败先怀疑探针，第二种手段复核。⚠️ 超几十 KB 不进 localStorage（**静默失败**）。搜中文用 `Grep` 工具（BSD grep 静默失配）；**同一文件不要在一次消息里发两个 Edit**。

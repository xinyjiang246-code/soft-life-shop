# 慢活小铺 · 项目长期约定

> **这是一张红线清单，不是手册。** 操作细节、100+ 条坑点、脚本用法一律见 skill `soft-life-web-dev`；用户原话见各日 `YYYY-MM-DD.md`。
> 本文件过长会在注入时被截断（尾部先丢），所以**只写「不这么做就会错」的东西**，细节写 skill。

## 一、是什么 / 为什么

- **初衷**：不饿/吃撑时仍想点一次外卖 —— 要的是下单仪式；食物不被真消耗，钱流向公益（捐猫粮按克计）。
- **结构** = 真外卖 App：`home → counter → cart → checkout → delivery → ending →（捐猫粮）→ charity`；`world`（世界菜单）· `rescue`（惜食柜）两条独立入口走同流程，返回用 `from` 参数。
- **6 家店**：tea / bento / dessert / life / noodle / dimsum。**不再开新店新品类**；规模红线（用户「我们现在比较小」）：欠 4 样食物，**别再自己加东西**。
- **定位（2026-09-16 定档）**：面向陌生人的开放产品，走「一个人的仪式」，**不用后端** —— 钱是真的、转账用户自己走，App 只换算克数 + 记账。红线：**绝不暗示"我们替你捐了"**。给 AI 起私名提案已撤回（"我" = 小铺统一声音）。

## 二、三条最贵的红线

1. **🔴 结算页那句是全产品唯一一次「揭晓真相」**，不许退回旧版「你只是完整地经历了『挑选的快乐』」—— 那是别人也有、最没壁垒的部分（第十三节）。
2. **🔴 等待凭证只开给等满的那一份，快进买不到** —— 这条规矩本身就是护城河，不是奖励（第十二节）。
3. **🔴 打卡 / 目标 / 奖励一律不许**：不做连续打卡、不设目标、不做趋势图、不催单；惜食柜不要红色/倒计时/「仅剩 N 件」（第七节）。

## 三、商品图 · 公益

- 一律 `ItemArt.jsx`（real=店铺/购物袋，draw=小店/手账）；无图用 `DishArt` 蜡笔 SVG，**禁 emoji**；每款两张独立图（禁上下拼接），翻面 `FlipImage`；WebP，**禁 1MB PNG 进 dist**。
- 生成确定性：种子只来自 `(城市,批次,日期)`，**绝不用 `Date.now()`**（凭证编号同理，由 `dateSeed()` 派生）。世界/惜食商品不进 `getAllItems()`，只挂 `getItem()`。
- `CHARITY`：**100g/元**、60g/猫日、**默认 30%（不鼓励全捐）**、presets [10,30,50,100]；key `soft-life-charity-v1`。档案页必须诚实「这是一本账，不是一次转账」。

## 四、配送等待 · 慢活额度（核心机制）

时间是唯一真实资源 → 给时间定价，**不加小活动**。额度 `soft-life-patience-v1`：每天 10 分钟，快进按 `ceil(剩余秒/60)` 扣；不够则禁用；**等满不扣还多掉贴纸**（`waited` 记次数，只有等待页额度面板 + 首页「今天」读它）。加速 = **催单仪式**，**永不退回一键跳过**。

- **陪等方式三选一**：walk / road / offline，`soft-life-wait-mode-v1` 记住上次。**小游戏口径**：可以做，但不计分、不会输、**不点也完全没事**。walk 的选择进结局页「路上的纪念」——只记事，**不给奖励**。
- 🔴 **三种方式必须「互斥切换」，不是「常驻进度窗 + 追加模块」**（用户原话「选了没变化」）。统一挂在一张 `.wait-deck` 外壳下，三个子组件**只出主体，不许自带抬头**。守卫 `verify-wait-modes.mjs`。

## 五、首页

- hero = 杂志内页（THE SOFT HOUR）；改高度同步 `.hero-cap`。
- 氛围条 · 每日心情（`soft-life-mood-v1`）· 软软串门 · 2×2 磁贴（统一水彩图；**别再塞新入口**；猫视角 = 正面平视左右对称）。顶栏搜索/心愿单是真入口；新增商品能力**同步进搜索索引**。心愿单语义 =「先记着不急着点」。
- **氛围条那张卡里还挂着「今天」这一条**（第十四节）。
- 🔴 **UI 视觉改造分三刀，都只动字体与印刷手段，没动布局/配色/图片**：① 字型层（全站字体只从 `:root` 五个角色变量取，微标签统一 mono）② 印刷层（只取四样：颗粒纸面 · 硬阴影 · 1px 实线 · 印章；**不吃**大圆角+柔和阴影）③ 字阶层（只在同一支 Fraunces 内开三档：**重音**斜体 800+WONK / **标题**正体 500→600 / **中文大标题**宋体 Bold）。
  - 🔴 **重音层靠「少」成立** —— `verify-typekit.mjs` [4] 写死**同一页上限 5**，**加了新落点不许顺手抬上限**。要加重音落点前先看这条。
  - 暂停期的规矩仍有效：**用户不给方向就不动任何页面视觉、不许自己归纳方向**。下一页（demo 的页码/装订线）等用户点头。

## 六、软软（猫）与表情

- 形象 = 猫（别退回兔熊 SVG）；氛围词用「小饼干」不写「猫粮」。素材 `assets/pets/`；两条取图出口 `.pet-photo` / `.neighbor-cat`，**用 glob 的 key 取 value**。出图链 petForge → **必须顺手 petKnockout**。三层动画分开挂（同元素两个 transform 会互相覆盖）。
- **三只猫的摸法已统一**：小屋 `PetScreen`（150px，传 `faces`，6 部位 + 7 表情）· 首页 `HomeCat`（58px）· 等待页 `.wait-pet`（64px）。后两只**也做六部位形变 / 按部位台词 / 心情角标**，共用 `petTouch.js` 的 `zoneFromPoint` / `playPatReaction` / `patLine` / `MOOD_BY_ZONE`。**接第四只猫照同一套接，别各写一份**。
  - 后两只**不画脸**的理由是尺寸（150px 时眼睛才约 7×9px，58/64px 只有 ~3px），改用**角标**。**想加脸的前提是先放大 —— 那是动布局，得用户点头**。
  - 两个磨掉的瑕疵（别改回去）：① 里程碑原按「会话累计点击数」→ 摸到第 3 下不管摸哪儿都说同一句，**把「分部位」整个吃掉**；现按「**同一部位连续摸**」计数。② 摸爪子原来是 `startle`（受惊）配「尾巴慢慢竖起来了」（猫语里是开心），**表情和话正好相反**。
  - 等待页**不加气泡**（那张卡会盖住上一张）—— 复用卡片原有那行文字当台词出口。
- 表情：`petFace.py` 量锚点 → noeye 图（**MaxFilter 膨胀，禁扩散填充/腐蚀**）→ `PetFace.jsx` 重画五官；锚点 `src/petFace.js` 别手改。**只有宠物页传 `faces={true}`**（首页开了会吃掉摸猫点击）。量到的点是 **nose 不是 mouth**。

## 七、惜食柜 · 手账

- **惜食柜**：定位「关门前剩下的几份」，**不是促销**。账本主角是份数。每天 3 件、折率 30/40/50%（**互不相同**）、每件 2 份、独立 `rescue-` id（原价绝不改写）、种子只来自 `dateSeed()`、记账在结局页。
- **手账**：图必须是用户自己拍的照片。原图压 1600 WebP 进 **IndexedDB**，localStorage 只留 180px thumb；**删条目必须同时删照片**。手账是唯一存储，共用 `EntryDetail.jsx` / `journalMeta.js` / 字段白名单 `JOURNAL_FIELDS`（新增字段只改这里）。两步点开：`.jh-peek`（**必须不透明**）→ `.jh-detail-panel`。
- **热量规则收窄**：可自记，但**不求和、不设目标、不做趋势图**。记账时机 = 结局页（**送达才算数**）。列表行上不放删除。
- 验收素材 `tools/seedPhoto.mjs` 用项目真照片 ——**交付图里的测试素材必须一眼认得出是食物**；断言阈值从素材推导，别写死。

## 八、技术 / 验证（只留最贵，细节见 skill 坑点）

- 预览：`python3 -m http.server 8080 --bind 127.0.0.1`（cwd=`dist/`）；别让用户开 `file://`（白屏）；`base:'./'` 不能动。
  - ⚠️ 判断「服务在不在」用 `curl --noproxy '*'`：本机 curl 走沙箱代理返回 502，且 `lsof -ti:8080` 会匹配到「远程端口是 8080 的连接」而误判。
- **购物袋金额只有一处实现**：`cartBreakdown(cart)`；对账 effect（角标与真实内容一致），新增每日商品来源要挂上。
- ⚠️ **build 绿 ≠ 接线对**（rolldown 不查作用域）：改回调 prop / `useMemo` 依赖数组后必须真机走到那页。
- ⚠️ **假警报比漏报更贵**：断言失败先怀疑探针，用第二种手段复核，最后才改产品。`waitFor` 条件选「只有成功才出现」的；探针用明确类名。
- ⚠️ **CDP 截图**：抓不到动画中间帧（会等合成器稳定）→ `pause()` + 设 `currentTime` 冻住；`clip` + `captureBeyondViewport` 和 `setDeviceMetricsOverride` 一起用会捕到**空白纸**；截「刚渲染完」的页面等待时长别卡着动画时长（`.26s` 动画要等 700ms）。
- ⚠️ 超几十 KB 不进 localStorage（**静默失败**）；盖层必须不透明（量 alpha）；「状态写了没人渲染」按数据问题查（它从哪进来？在哪被读出去？）。
- 搜中文用 `Grep` 工具（BSD grep 静默失配）；改完 `.mjs` 先 `node --check`（但它**只解析不解析 import**，还得真跑一次）。
- **同一文件不要在一次消息里发两个 Edit** —— 会互相覆盖，两边都报成功但只有一处落盘。

## 十、交互层（2026-09-18）

三件事，**都没动玩法 / 布局 / 配色**。细节与两条被否掉的路见 skill。

- **切页进场**：屏幕根节点的**子元素**做 `opacity` + `translate`，方向在 `<html data-nav>`，`.bottom-bar` 排除。动画 260ms，填充必须 `backwards`。
  - 🔴 两条**被实测否掉**的路别走回去：① 给页面套 transform → 换掉 `.bottom-bar` 的包含块；② **View Transitions** → 转场中 Chrome 不让实时内容参与命中测试，每次切页 ~260ms **全页点不动**。
- **全局点击手感**：`:active` 压 .07s + 按尺寸分组 scale（图标 .86 / chip .93 / 大块面 .994）。**用独立 `scale` 属性不用 transform**。`.flip-toggle` 例外。
- **加购动线**：`src/flyToBag.js` 飞点上抛弧进袋子 → 袋子晃 + 角标弹。**纯视觉，不参与业务**。购物袋按钮独立成 `.bag-button`（原来和心愿单共用 `.cart-button`）。数量/合计用 `key={qty}` 重挂重播 `numPop`。
- 守卫 `verify-interactions.mjs`（最贵一条：**进场动画还在跑时真实鼠标点击必须有效**）。交付图 `预览截图/交互_*.png`。

## 十一、等待凭证（2026-09-18）

**背景**：同类产品已成一整个品类（韩国 `FoodNeverComes` 131 万次 / 假打针）。结论：**机制层面不新**，但那条线**全是假装**（省下的钱只是屏幕上的数字，代价为零）。这里的两样他们没有：**时间要付代价** + **钱是真的出去**。所以这一步**不加玩法**，是把已发生的事做成一张能拿给人看的纸。

- `params.wait.waited` 为真才渲染；未等满只给一句诚实说明。三文件别拆散：`src/receiptImage.js`（Canvas PNG，字体从 `:root` 取 + 导出前 `await document.fonts.ready`）· `WaitReceipt.jsx` · `EndingScreen.jsx`。
- 纸上五行：收件 / 这一单 / 没变成 / 记下的猫粮（**捐赠前是「—」**）/ 今天等满。
- 🔴 **纸上不许出现「已替你捐」**；小字固定「钱还在你手上 —— 记多少，你自己定。」克数**必须等用户真的按下捐赠才出现**。
- ⚠️ 重音规则**只能写字号/颜色，禁用 `font` 简写**（会把斜体/800/WONK 重置）。⚠️ 章**必须给纸留底边**，否则压住那句话。
- 守卫 `verify-wait-receipt.mjs`，最贵一条：**存下来的 PNG 不是空白纸**（落盘尺寸 + 灰度种类）。

## 十二、新人第一眼 / 产品怎么介绍自己（2026-09-19）

做法：**清空 localStorage，当自己是从没听过的人走完整条线**，记录每一步告诉用户什么。结论：**缺口几乎全在「产品怎么向人介绍自己」，不在功能里**。四处一次做完，玩法/布局/配色一个没动。

- **🟠 首/回访分开**：`hasVisited()` / `markVisited()`（`soft-life-visited-v1`），判据是「这台设备来过没有」而不是「下过单没有」；读失败**当来过**。
- **首页底部 `.about-shop`** 交代铺子是谁开的 —— 全站唯一一处说「我」是谁。标题走 mono 小字，**不挂 `.section-title`**。
- **账本补一段「可以捐给谁」**（投喂点 / 大学猫协 / 救助小店），仍守红线且不催。

守卫 `verify-first-visit.mjs`（末段**扫构建产物**查全站红线）。交付图 `预览截图/新人第一眼_交付.png`。

## 十三、首页「今天」（2026-09-19）

**第十二节解决「第一次看懂」，这一节解决「第二天还来」** —— 同一个诊断的两半。
诊断：每日心情 / 今日特调 / 惜食柜 / 慢活额度 / 手账 / 世界菜单**全是「每日」的，却没有一处把它们串成「今天」** → 第二天打开看到的和昨天一模一样。

- 位置：氛围条**那张卡里**加一条（同一个 `.home-ambience` 内，不另起卡片）。`src/today.js` 聚合。
- 两态互斥：**态 A**（今天做过事）`今天等满 N 单` / `存下 N 餐 · 记下 N 克猫粮`；**态 B**（今天还没发生什么）`今天的特调是「X」` / `惜食柜 N 份 · 今日空运 <城市>` —— **态 B 只放每天真的会换的东西**，它的任务就是让人一眼看出「这是新的一天」。
- 🔴 **不新增任何存储**：全是已经在记的，只是以前没人读出来（最典型是 `patience.waited`）。
- 四条数据源日期口径**不同别搞混**：`patience` 与手账用 `YYYY-MM-DD`，`charity`/`rescue` 的 `records[].at` 是 **ISO 时间戳**（按本地时区比）。
- 🔴 **措辞红线**：全陈述句，不许「还没 / 快去 / 今日目标」。态 B 说的是**今天有什么**，不是**你还缺什么**。**心情不算「今天发生过事」**（`MoodRitual` 就在下面，会重复）。
- 它**不可点、没有箭头**：一可点就会变「栏目」，而它不该有内容页。分隔线别用 `--divider`（叠在那层浅色渐变上看不见）。
- 守卫 `verify-today.mjs`，**最贵的是「跨天」**：注入**昨天**的账必须回到态 B —— 有人把判断改成「累计 > 0」就会红（累计面板是 KPI，今天才是日子）。交付图 `预览截图/今天_交付.png`。

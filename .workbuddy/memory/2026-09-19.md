## 一、等待凭证（结局页）

**为什么是这个方向**（别丢）：用户发现有别人在做同类东西（假打针「就来一针」/ 韩国
`FoodNeverComes`「外卖不会来」，131 万次），担心「我们不独特了」。查实的结论是
**机制层面确实不新**（都是「多巴胺在期待里」那一套），但那条线**全是假装** ——
省下的钱只是屏幕上的数字、药是假的、代价为零，所以只能是个玩笑，玩两次就空。
这里有两样他们没有的：**时间要付代价**（慢活额度，等 25 分钟是真等）、
**钱是真的出去**（按克记，账本在档案页）。所以这一步**不是加玩法**，
而是把已经发生的事做成一张能拿给人看的纸 —— **那张纸是唯一的护城河**。

### 纸上的内容与红线

- 五行：收件（店名）/ 这一单（¥金额）/ 没变成（一份没人吃的外卖）/
  记下的猫粮（**捐赠前是「—」，不许先写个数骗人**）/ 今天等满（第 N 次）。
- 🔴 **纸上不许出现「已替你捐」**（与公益那条同源）。小字固定
  「钱还在你手上 —— 记多少，你自己定。」克数**必须等用户真的按下捐赠才出现**，
  且随捐赠状态实时重算（守卫 [2] 盯这条）。
- **只开给等满的那一份，快进买不到** —— 这条规矩本身就是护城河，不是奖励。

### 排版：不引入任何新手段

纸面 = 已有的颗粒 + 1px 实线；章 = 已有的 `.print-seal`；那句英文
（`the wait was real.`）走已有的**重音声部**（`.wr-accent` 加进 `verify-typekit` 的 `VOICE`）。
⚠️ 那条规则的 CSS **只能写字号/颜色，禁用 `font` 简写** —— 简写会把
`font-style` / `font-weight` / `font-variation-settings` 一起重置回正的，那一句立刻不斜也不重。

### 两处坑

2. **撕口那把剪刀**：12px 下糊成一团，而且它垫的白底在颗粒纸上露出一块 →

### 重音层上限的口径（改了）

加第 4 个落点 `.wr-accent` 时定的**新规矩**：`verify-typekit` [4] 的 5 是

新落点跟老的通常不在同一页，压根数不进那次统计，抬上限等于把保护拆了。

## 五、诊断：「这个作品还是不完善，但说不清在哪」（2026-09-19 用户提问）

做法：清空 localStorage，当自己是从没听过这个产品的人，走完整条线
（首页 → 店铺 → 购物袋 → 结算 → 等待 → 结局），记录每一步**告诉用户什么**。
结论：**缺口几乎全在「产品怎么向人介绍自己」，不在功能里。**

1. **最要紧的一句把自己说小了** —— `CheckoutScreen.jsx:72`：
   「这是一份虚拟订单，不会真的扣款，也不会真的送来任何东西。你只是完整地经历了「挑选的快乐」。」
   前半句必须留；后半句把产品定义成「选东西的乐趣」，而那恰是别人也有、且最没壁垒的部分
   （假购物车谁都能做）。这一单真正发生的是：花掉 2 分钟真实时间 + 记一笔猫粮 + 一张带「等满」章的纸。
   **产品有别人没有的东西，却在自我介绍时说了别人也有的那一样。**
2. **全产品没有一处交代「铺子是谁开的」** —— 声音一直是第一人称「我」，但「我」是谁从没出现。
   一个让你去捐猫粮的东西，不说自己是谁，可疑度翻倍。也是最便宜的一块（三四句话）。
3. **承诺钱去捐猫粮，但没给可行路径** —— 「我真去捐了」只让填克数/给谁，
   全 App 唯一提示是输入框 placeholder「比如：北大猫协」。面向陌生人时这正是新用户要的「下一步」。
4. **陌生人第一句就被穿帮** —— 清空存储后首页仍写「下午好，欢迎回来」。
   且首页对陌生人**完全不解释自己**（很美，但 3 秒内说不出能干什么），下面又长得完全是真外卖。
5. **第二天为什么回来** —— 每日心情/每日特调/每日 3 件/每天 10 分钟额度/软软成长，
   全是「每日」的，但没有一处把它们串成「今天」。回来看到的是和昨天一样的首页。

小瑕疵：`CheckoutScreen` 的「这一单 02」里那个 02 是**件数**（`cartBreakdown().count`），
摆在像编号的位置上会被误读成订单号。每店只有 3–4 件在售，「逛」的体量不够。

⚠️ 差点误报的一条：以为「购物袋/购物篮」术语不一致 —— 实际代码注释用「购物袋」、
**UI 文案统一是「购物篮」**（CartScreen/main.jsx/data.js 全站一致），不是问题。别当真警报报出去。

### 这次踩的坑（已进 skill 坑点 99-100）

- ⚠️ **`useMemo` 依赖数组里写错变量名 → 构建全绿、页面直接白屏**：
  写成 `[cartCount, petMeals, isFirstVisit]`，而那个作用域里只有 `pet.meals`。
  rolldown / esbuild **不查作用域**，构建输出「✓ built」，运行时 `ReferenceError: petMeals is not defined`，
  `#root` 整个空的（只剩米色底）。**「build 绿 ≠ 接线对」的典型形态**，改依赖数组时最容易犯。
  查法：`--dump-dom` 看 `#root` 空不空，或一次性脚本读 `root.innerHTML.length`。
- 扫 bundle 做「全站文案红线」守卫，**必须先断言读到了已知文案**再断言「不包含」，
  否则 bundle 改名 / 忘了构建 → 扫到空内容 → 否定断言全是假绿。

## 一、等待凭证（结局页）

**为什么是这个方向**（别丢）：用户发现有别人在做同类东西（假打针「就来一针」/ 韩国
`FoodNeverComes`「外卖不会来」，131 万次），担心「我们不独特了」。查实的结论是
**机制层面确实不新**（都是「多巴胺在期待里」那一套），但那条线**全是假装** ——
省下的钱只是屏幕上的数字、药是假的、代价为零，所以只能是个玩笑，玩两次就空。
这里有两样他们没有的：**时间要付代价**（慢活额度，等 25 分钟是真等）、
**钱是真的出去**（按克记，账本在档案页）。所以这一步**不是加玩法**，
而是把已经发生的事做成一张能拿给人看的纸 —— **那张纸是唯一的护城河**。

## 五、诊断：「这个作品还是不完善，但说不清在哪」（2026-09-19 用户提问）

做法：清空 localStorage，当自己是从没听过这个产品的人，走完整条线
（首页 → 店铺 → 购物袋 → 结算 → 等待 → 结局），记录每一步**告诉用户什么**。
结论：**缺口几乎全在「产品怎么向人介绍自己」，不在功能里。**

1. **最要紧的一句把自己说小了** —— `CheckoutScreen.jsx:72`：
   「这是一份虚拟订单，不会真的扣款，也不会真的送来任何东西。你只是完整地经历了「挑选的快乐」。」
   前半句必须留；后半句把产品定义成「选东西的乐趣」，而那恰是别人也有、且最没壁垒的部分
   （假购物车谁都能做）。这一单真正发生的是：花掉 2 分钟真实时间 + 记一笔猫粮 + 一张带「等满」章的纸。
   **产品有别人没有的东西，却在自我介绍时说了别人也有的那一样。**
2. **全产品没有一处交代「铺子是谁开的」** —— 声音一直是第一人称「我」，但「我」是谁从没出现。
   一个让你去捐猫粮的东西，不说自己是谁，可疑度翻倍。也是最便宜的一块（三四句话）。
3. **承诺钱去捐猫粮，但没给可行路径** —— 「我真去捐了」只让填克数/给谁，
   全 App 唯一提示是输入框 placeholder「比如：北大猫协」。面向陌生人时这正是新用户要的「下一步」。
4. **陌生人第一句就被穿帮** —— 清空存储后首页仍写「下午好，欢迎回来」。
   且首页对陌生人**完全不解释自己**（很美，但 3 秒内说不出能干什么），下面又长得完全是真外卖。
5. **第二天为什么回来** —— 每日心情/每日特调/每日 3 件/每天 10 分钟额度/软软成长，
   全是「每日」的，但没有一处把它们串成「今天」。回来看到的是和昨天一样的首页。

小瑕疵：`CheckoutScreen` 的「这一单 02」里那个 02 是**件数**（`cartBreakdown().count`），
摆在像编号的位置上会被误读成订单号。每店只有 3–4 件在售，「逛」的体量不够。

⚠️ 差点误报的一条：以为「购物袋/购物篮」术语不一致 —— 实际代码注释用「购物袋」、
**UI 文案统一是「购物篮」**（CartScreen/main.jsx/data.js 全站一致），不是问题。别当真警报报出去。

每日心情 / 今日特调 / 惜食柜 / 慢活额度 / 手账 / 世界菜单**全是「每日」的，

### 做法

`src/today.js`（新）+ 氛围条那张卡里加一条（同一个 `.home-ambience` 内，**不另起卡片**）。
两态互斥：

- **态 A**（今天做过事）：`今天等满 N 单` / `存下 N 餐 · 记下 N 克猫粮 · 带走 N 份`
- **态 B**（今天还没发生什么）：`今天的特调是「X」` / `惜食柜 N 份 · 今日空运 <城市>`
  —— **态 B 只放每天真的会换的东西**，它的任务就是让人一眼看出「这是新的一天」

🔴 **不新增任何存储**。所有数字都是已经在记的，只是以前没人读给用户看 ——
最典型的是 `patience.waited`（今天等满了几单）：它一直在账里，
却只有等待页那块额度面板读过一次，**离开那页就没人再看见**。

四条数据源的日期口径**不同，别搞混**：`patience`（`todayKey()`）与手账（`journalKey()`）
用 `YYYY-MM-DD`；`charity.records[].at` 与 `rescue.records[].at` 是 **ISO 时间戳**
（按本地时区比 `getFullYear/Month/Date`）。

**措辞红线**：全陈述句，不许「还没 / 快去 / 今日目标」。态 B 说的是**今天有什么**，
不是**你还缺什么**。**心情不算「今天发生过事」**（那是此刻的选择不是记下的一笔，
而且 `MoodRitual` 就在正下方会重复）。它**不可点、没有箭头** —— 一可点就会变「栏目」，
而它不该有内容页。

### 这次踩的坑（已进 skill 坑点 101-104）

1. ⚠️ **`evaluate(homeReady)` 只求值一次，不是「等」**：页面没渲染完时返回 `false` 就往下走，
   紧接着的 `querySelector(...).innerText` 报 `Cannot read properties of null` ——
   看着像选择器写错，其实是没等。要用 `waitFor()` 那种轮询。
2. ⚠️ **`clip` + `captureBeyondViewport` 和 `setDeviceMetricsOverride` 一起用会捕到空白纸**：
   背景色在、内容全无，**而同一时刻 `innerText` 读得好好的**（它不看 opacity、也不看截图参数）。
   稳的做法：不带 clip 直接截视口，要哪块后面用 Pillow 裁。
3. ⚠️ **截「刚渲染完」的页面，等待别卡着动画时长用**：切页进场是 `.26s`，
   脚本写 `sleep(260)` 就截到 opacity 还在 0.x 的那一帧 —— 又是一张空白纸。写 700ms。
   （2+3 合起来：**「截图空白」先怀疑等待与截图参数，别先怀疑页面**。）
4. ⚠️ **`lsof -ti:8080` 会匹配到「远程端口是 8080 的连接」，不只是本地监听**：
   微信的一条 outbound 连接让 `lsof` 有输出，`... && echo 已在跑 || 启动` 于是**把真正的启动跳过了**，
   服务其实没起。判断服务在不在要用 `curl --noproxy '*' -o /dev/null -w '%{http_code}'`；
   另外**本机 curl 走沙箱代理会返回 502**（不是服务的问题），必须加 `--noproxy '*'`。

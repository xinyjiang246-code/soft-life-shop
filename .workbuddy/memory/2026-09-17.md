# 2026-09-17 · 软软的表情

> 承接 09-16 的「点不同部位 → 身体做不同动作」。用户一句话开启本轮：**「表情也可以变呀」**。

## 用户要什么

身体已经在动了，但**脸一直是同一张**。用户要的是脸也跟着变 ——
不是「整个头缩放一下」那种假变，是眼睛真的换成眯眼 / 弯月 / 瞪大 / 爱心 / 星星。

## 核心难点与解法

软软是**一张扁平水彩图**，五官画死在像素里，动不了。所以走「换底图 + 重画五官」：

1. `tools/petFace.py` **量锚点** —— 二分连通域找眼睛，按形状筛（`area>=300 / fill>=0.45 /
   0.45<=w/h<=2.2 / max(w,h)<=70`）。**不能用腐蚀去噪**：眼睛是环形带白高光，腐蚀 7px 会把
   整只眼睛吃掉，一个阶段都认不出来。嘴 = 眼睛连线下方最近的小团。顺带出每阶段的 `tilt`
   （阶段 3/4 的脸是歪的）。
2. 同脚本出**无眼底图** `src/assets/pets/noeye/a-cream-stage{n}-t.webp`：
   近白底 → `ImageFilter.MaxFilter(3)` 膨胀 → 高斯模糊 → 椭圆羽化。
   **必须是「形态学最大值」**：Jacobi 扩散填充会把眼睛周围那圈灰水彩晕抹进来（染色），
   纯色填充会留色差（脸不是纯白，左边近白右边偏灰）。最大值法只吃最亮邻近毛色 → 不带暗像素 → 不要配色。
3. `src/petFace.js`（**自动生成**）存锚点 → `components/PetFace.jsx` 照锚点画 SVG 表情。

**图层纪律**（这是关键，两个 transform 动画会互相覆盖）：
`.pet-idle`（呼吸）→ `.pet-hit`（WAAPI 形变）→ 底图 img → `.pet-noeye`（`is-on` 切换）→ `.pet-face`（SVG）。
**五个独立元素，各管各的。**

## 定下来的七个表情

| 触发 | 表情 | 画法 |
|---|---|---|
| 摸耳朵 | `squint` | 半闭细眼缝 |
| 摸头顶 | `bliss` | ∩ 弧线闭眼 + 飘光点 |
| 摸左右脸 | `smile` | ＞＜ 眯眼（**左右镜像**，同向像抽搐）+ 脸红 |
| 摸肚子 | `purr` | ◡ 弯月眼 + 两侧呼噜弧线 |
| 摸爪子 | `startle` | **白眼球放大 + 瞳孔缩小** + 汗滴 + 两根惊线 |
| 连点 3 下 | `heart` | 眼睛变爱心 |
| 连点 5 下 | `star` | 眼睛变星星 |

- `FACE_HOLD = 1150ms` 后自己收回本来那张脸；升级走 `expressionFor(zone, heat)`，`HEAT_WINDOW = 1500ms`。
- **`startle` 改过一版**：初版「放大黑眼球 + 高光」跟平常那张脸几乎一样，看不出受惊 →
  改成「白眼球放大 + 瞳孔缩小」，这才是「惊讶」的视觉约定。
- 提示语同步改成「摸摸它 —— 点耳朵、肚子、爪子，**表情和动作**都不一样」
  （09-16 那版只说了「反应」，本轮补上表情）。

## 两个踩过的坑（已写进 skill 坑点 53–56）

1. **`Page.captureScreenshot` 的 `clip` 是页面坐标**，不是视口坐标。进页面先 `scrollIntoView` 过，
   不加 `scrollX/scrollY` 会截到别处 —— 表现是「图看着像猫，但跟标注的表情对不上」，
   差点误判成表情画错了。
2. **注入 `Runtime.evaluate` 的模板字符串会被 Node 先解释一遍转义**：写 `/\\s+/` 到浏览器变成 `/s+/`，
   把 `"squint"` 匹配成 `" quint"`。

# 第二轮 · 用户「你看看可不可以再看看有什么改进」

## 查出来的四个真问题（都是先取证、再动手，不是凭感觉提建议）

1. **`petFace.py` 量到的那个点其实是鼻子，不是「鼻子嘴」** —— 字段名 `mouth` 是错的。
   放大 7 倍看鼻子下方：**只有水彩纸纹，没有嘴**。也就是说软软**本来就没有嘴**，
   七个表情共用同一张下半脸 —— 只有上半脸在演，`startle` 那张尤其别扭（眼睛瞪得老大，
   嘴却一如既往地平静）。已把字段正名为 `nose`，并**把嘴做成表情的一部分**。
2. **嘴的尺寸按眼距算，导致 `flat`（眯眼那条浅弧）只有 3 个 viewBox 单位高** ——
   宠物页软软只有 150px 宽，换算过去不到 1 个 CSS 像素，**等于没画**。
   改成跟眼睛半高 `ry` 挂钩（眼睛就是 32×44 这个量级，嘴只能跟它同一尺度说话）。
3. **ω 嘴的路径不对称**：第二段贝塞尔只写了 `w/1.5`，整条路径止于 `+0.33w` →
   嘴整体偏到鼻子左边 1/3 个嘴宽。小尺寸下就是「嘴歪了」。
4. **`.pf-mark` 的弹出动画原点错了**：SVG 元素的 CSS `transform-origin` 默认是 `0 0`
   （整个 viewBox 左上角），所以小爱心是从**版面左上角飞进来**的，不是原地弹出。
   加 `transform-box: fill-box; transform-origin: center` 修掉。

顺带的观感调整：**爱心眼改玫瑰色、星星眼改金色**（原来用眼珠的深棕，跟旁边飘着的粉爱心
不像一件事），并加上**呼噜时两侧弧线的嗡鸣感**（原来只是一圈静止的括号）。

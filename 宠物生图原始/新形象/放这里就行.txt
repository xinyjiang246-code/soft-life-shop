把你的新形象图片直接丢进这个文件夹（PNG / JPG / WebP 都行）。

出图用的 prompt 见项目根目录 → 宠物形象生图prompt.md（水彩版，2026-09-14 定版）。
参考图在 → 宠物生图原始/参考图/水彩小熊参考_20260914.jpg

我在意什么：

1. 5 张 = 5 个成长阶段。文件名里带 stage0 ~ stage4 最好（比如 stage2.png）；
   没写编号也行，我会按文件名顺序依次当作 stage0~stage4。
2. 透明背景 PNG 最好；带背景也能用（会合成到米色底 #F6F1E8，不会出白方块）。
3. 正方形或竖图都行 —— 我会**自动找到角色本体**按 220:248 重新构图，所以：
   形象居中、四周留点空就行；图上万一带了小道具也不会歪。
4. 别要文字、水印、签名、边框。底部 6% 会被自动裁掉（去水印用）。
5. 5 张必须像同一只，只有耳朵 / 配饰 / 表情按阶段变。**一致性比单张精美重要。**

★ 别一次出 5 张。先只出 stage2（垂耳兔熊 = 软软默认展示的那个阶段）丢进来，
   我处理 + 打包给你看真实尺寸效果，方向对了再铺满其余 4 张。

丢完跟我说一声，我跑 tools/petForge.py 处理 + build，App 里就换成你的形象。

手动跑（可选）：
    python3 tools/petForge.py --only 新形象 --colorway cream
    npm run build
